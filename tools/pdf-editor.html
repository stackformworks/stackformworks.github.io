PDF Editor

Edit existing PDF text, add highlights or a signature, and organize pages in your browser.

Type your text, then click where its baseline should appear. With a keyboard, focus the PDF preview and press Enter to place it at the center.

How to edit a PDF

Open a PDF and choose a page. Choose Edit existing text, select a text run, enter the new text, and apply the replacement. You can also add text, highlights, or a signature and organize pages. Undo restores the last edit. Download saves a new copy.

What this editor supports

Existing text can be replaced in supported text-based PDFs. Replacement uses the original font, stays selectable, and keeps the surrounding layout. Scanned pages, some embedded fonts, and text split across multiple runs may have no editable text. The Add text tool also supports Sinhala. Downloading edits can invalidate digital signatures.

Need to combine separate documents? Use Merge PDF.
