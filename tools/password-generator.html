How to use this tool

  1. Choose a length. The default is 20 characters, and you can select a different length to fit the account’s requirements.
  2. Select the character groups the account accepts. Leave at least one group enabled. Use the similar-character option if you expect to type the password by hand.
  3. Select Generate password after changing your options. Each generated password contains at least one character from every enabled group.
  4. Copy the result and save it in your password manager or paste it into the account form. Generate a separate password for each account.

Features and privacy

ToolVibe uses your browser’s Web Crypto random number generator. The password is generated on your device and is not sent over the network or saved by ToolVibe. Once copied, it is available to your device’s clipboard and any clipboard history or syncing features you use. Clear it there after use if your device retains a history.

Long passwords drawn from a broad set of characters give an attacker more possibilities to guess. Some account forms restrict allowed symbols or maximum length. Choose compatible settings for that account and use as much length as the service reasonably permits. Keep the result somewhere you can retrieve it securely, especially when it is too long to memorize.

Frequently asked questions

Will it include a number when numbers are enabled?

Yes. Every enabled group contributes at least one character. The selected characters are then shuffled using the same browser random source.

Which characters does the similar-character option remove?

It removes common lookalikes from the allowed groups, including zero, uppercase O and I, lowercase o and l, 1, and the vertical bar.

Why does Copy password sometimes fail?

Some browsers block clipboard access when the site opens from a file or an insecure address. You can select the displayed password and copy it manually. A hosted HTTPS version usually allows the button when clicked directly.
