How to use this tool

  1. Choose Website URL, Plain text, or Wi-Fi network. A URL opens a web page, plain text displays a message, and a Wi-Fi code shares connection details with compatible devices.
  2. Enter the complete address or message. For Wi-Fi, enter the network name exactly as it appears in device settings, then select the security type and enter the password if the network requires one.
  3. Select Generate QR code and scan the preview with a phone. Check the destination, the displayed text, or whether the phone can join the intended network.
  4. Download PNG for a regular image or SVG for a design project. Keep the white margin when you place the code on a flyer, label, slide, or sign.

Features and privacy

The QR pattern is created in your browser from the information you enter. ToolVibe does not send that information to a QR service or store it in browser storage. A downloaded QR code still contains the supplied information. Anyone who can scan a Wi-Fi code can read the connection details, so place it where the intended guests can see it.

You can print the same QR code at different sizes. SVG preserves crisp edges when resized, while PNG is easy to insert into most document and image editors. Longer messages create denser codes, so leave enough room for a camera to distinguish the smaller squares. Test the finished design at its intended size and from the distance people will scan it.

Frequently asked questions

Does the QR code expire?

The exported image contains the original information and has no built-in expiry. A website link can stop working, and Wi-Fi settings can change. Generate a fresh code when its contents change.

Why will my phone not scan it?

Try larger dimensions, better lighting, and a plain white margin. If you are printing on a reflective surface, test another angle or use matte material. Keep graphics and logos clear of the QR pattern.

Can I change the destination after printing?

The printed code encodes a fixed value. To reuse the same printed code, point it to an address you manage and update the content or redirect at that address.
