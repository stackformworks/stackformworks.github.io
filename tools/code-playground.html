    How to use the playground

    1. Paste a snippet or a complete HTML document in the HTML tab. A complete document can include its own inline styles and scripts.
    2. Use the CSS and JavaScript tabs to add extra styles and code. CSS from its tab is added after the HTML document's head styles. JavaScript from its tab runs after the HTML content is parsed.
    3. Select Run code. Use Mobile to check the layout in a viewport up to 390 pixels wide, and check the console for logs and errors.
    4. Choose Download HTML to save your current edits as a single file.

    Example: test a button before embedding it

    Paste <button id="demo">Click me</button> in the HTML tab. In the JavaScript tab, replace the sample code with document.querySelector('#demo').onclick = () => console.log('Clicked');. Select Run code and click the button in the preview to check the console output.

    Switch to Mobile to check whether the button fits a narrow viewport. Use Download HTML to save the HTML, CSS, and JavaScript together.

    Previewing an embed

    Paste your embed HTML and check the layout before adding it to a site builder. The preview blocks external scripts, stylesheets, images, and embedded frames. Use inline CSS, inline JavaScript, or data URL images for a standalone test. The destination site can apply its own rules to embedded code.
