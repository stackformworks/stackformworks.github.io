How to generate an SQL IN list

  1. Copy a single Excel column or paste a list of values. Keep Lines and tabs selected when a value contains a comma.
  2. Use a text format for order numbers, tracking IDs, or values with leading zeros. Choose Numbers only when the database column stores numeric values.
  3. Select Generate SQL list. Copy the output and place it after the column name in your WHERE clause, such as WHERE OrderNo IN ('FS412009', 'FS412011').

Example: paste order numbers from Excel

If your column contains FS412009, FS412011, and FS412009 again, leave Remove duplicates enabled. The tool produces IN ('FS412009', 'FS412011'). Add it after your column name, for example WHERE OrderNo IN ('FS412009', 'FS412011').

Keep Text selected for codes like 000421 so the leading zeros stay in the result. If your database column is numeric, choose Numbers to generate a list such as IN (421, 422).

Quotes and duplicates

The tool trims surrounding whitespace and skips blank entries. Duplicates are compared as typed after trimming, and their first occurrence stays in place. Text values are wrapped in single quotes, and embedded apostrophes are doubled. Use the MySQL text option when the server treats backslashes as escapes. Use standard SQL text mode if MySQL runs with NO_BACKSLASH_ESCAPES.

Frequently asked questions

Does it read quoted CSV?

The comma option treats every comma as a separator. If a value contains a comma, paste that value on its own line and use Lines and tabs.

Can this tool run my query?

The tool only formats a list for copying. In application code, bind user-supplied values with prepared statements. Check generated lists before using them in your own query.
